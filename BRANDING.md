# Envix branding and identity

This repository contains public documentation and brand assets; the production application source is maintained privately. The **Envix** name, Envix logo, visual mark, brand identity, and project presentation are separate from the software license.

Forks should use their own project name, logo, and visual identity unless explicit written permission is granted.
